Threat Model Lab

Import an architecture diagram or build one by hand, then generate a threat model four ways — enterprise IT or OT/ICS (Purdue), each as STRIDE-LM or RAPIDS scenarios. Every path resolves to MITRE ATT&CK TTPs, and each technique expands into an offensive attack/payload sample and the matching defensive controls with Sigma + YARA rules — the purple-team view I bring to system security risk assessments.

▲Authorised use only. Offensive samples mirror public MITRE ATT&CK, Atomic Red Team, Sigma and YARA references, for security testing and education. OT process-manipulation payloads are bounded to read/recon or isolated test-rig examples; live-process weaponisation is withheld. Diagram parsing is 100% in your browser — nothing you import is uploaded anywhere.
